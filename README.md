# Python OOP Assignment

This project demonstrates key Object-Oriented Programming (OOP) concepts in Python, including classes, objects, inheritance, and polymorphism. It uses East African countries as examples and includes a simple country management system for displaying country information.

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository with focus on the assignment_1.py file.
3. Copy and paste in a new file or in a new cell in jupyter notebook
4. Run the program
