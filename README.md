## Python OOP Assignment

This project demonstrates key Object-Oriented Programming (OOP) concepts in Python, including classes, objects, inheritance, and polymorphism. It uses East African countries as examples and includes a simple country management system for displaying country information.

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open the `Assignment_1.py` file in your preferred Python editor, IDE, or Jupyter Notebook.
4. Run the program to view the output.

## OOP Concepts Demonstrated

- Classes and Objects
- Inheritance
- Polymorphism

- Encapsulation




# TicTacToe_Project

## Tic_Tac_Toe_Game.ipynb

This project is a simple command-line Tic-Tac-Toe game developed in Python. The player competes against the computer, which makes random moves on the game board.

## Features

- Interactive Tic-Tac-Toe gameplay
- Player vs Computer
- Input validation for player moves
- Automatic win, loss, and draw detection
- Random computer move generation

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open the `TicTacToe_Project` file in your preferred Python editor, IDE, or Jupyter Notebook.
4. Run the program.
5. Enter a number from **1–9** to place your move on the board.

## Concepts Demonstrated

- Functions
- Lists
- Loops
- Conditional Statements
- Exception Handling
- Random Module Usage
